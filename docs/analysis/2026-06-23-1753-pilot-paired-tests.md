# 파일럿 설문 — 항목별 대응표본 t-검정 (통계 재분석)

> 작성 2026-06-23. 1차 분석([2026-06-16-1508-pilot-data-analysis.md](2026-06-16-1508-pilot-data-analysis.md))은
> 평균·중앙값 **기술통계**만 담았다. 이 문서는 그 위에 **추론통계**(항목별 대응표본 t-검정)를 얹는다.
> 재현 스크립트: `app/scripts/analyze-pilot-stats.mjs` (`npm run analyze:pilot`).
> 산출 표: 같은 폴더의 `summary_survey_stats.csv`.

---

## 1. 방법

### 왜 대응표본(paired) t-검정인가
각 참가자가 **베이스라인(Gamepad/키보드 메뉴)과 GlanceShift 두 조건을 모두** 경험한
within-subjects(반복측정) 설계다. 두 조건의 점수는 **같은 사람 안에서 짝지어져** 있어 독립이 아니므로,
독립표본 t-검정이 아니라 **대응표본 t-검정**을 항목마다 따로 적용한다.

핵심은 **차이값의 분산**이다. 검정통계량은

```
t = mean(diffᵢ) / ( sd(diffᵢ) / √n ),   diffᵢ = GlanceShift_i − 베이스라인_i
```

즉 유의성은 *겉보기 평균차*가 아니라 **개인별 차이값(diffᵢ)이 얼마나 일관되는가**(차이값의 분산)로
판가름난다. 평균차가 커 보여도 개인마다 차이가 들쭉날쭉하면 유의하지 않을 수 있고, 평균차가 작아도
모두가 같은 방향으로 움직이면 유의할 수 있다. (실제로 이 데이터에서 나타난다 — §3 참조.)

### 표본 구성 (참가자 11명, 임의 ID P1–P11)
- **설문1**(8행, 조건 라벨 있음): 연속 2행 = 한 사람 → **P1–P4**. 각자 두 조건을 따로 평가.
- **설문2**(7행, 한 행에 두 조건): 앞 4문항 = 1번째 경험 = **베이스라인**, 뒤 4문항 = GlanceShift →
  **P5–P11**. (조건 순서는 실험 진행 순서에 근거한 **가정**.)
- 11명은 서로 다른 사람으로 간주.

### 중복행 처리 — 주 분석 n=10, 부수 n=11
설문2의 `15:13:23`/`15:13:56` 두 응답이 **자유응답까지 완전히 동일**하다(P9·P10).
동일 응답이 두 번 들어가면 차이값 분산이 인위적으로 줄어 t값이 부풀려지므로, **중복 1행을 제외한
n=10 을 주 분석**으로 삼고, 1차 분석과 호환되는 **n=11(포함)을 부수**로 함께 싣는다.
⚠ 다만 설문 응답자는 11명으로 기억되므로, 만에 하나 두 응답이 *우연히 동일한 별개 응답*이라면
n=11 이 맞다. 두 표를 모두 제시하니 **최종 채택은 판단에 따라** 고른다.

### 보조 지표
- **Wilcoxon 부호순위검정**(비모수, 정규근사+연속성·동순위 보정): Likert(서열형)·소표본이라
  정규성이 의심되므로 t-검정 결과를 교차검증.
- **효과크기 Cohen's d_z** = `mean(diff)/sd(diff)` (대응설계용). 0.2 작음·0.5 중간·0.8 큼.
- 문항은 **원점수 유지**(flow_break 역코딩 안 함). `diff = GlanceShift − 베이스라인`이므로
  **흐름끊김(↓좋음)은 음수 diff 가 개선**을 뜻한다.

## 2. 결과

> 모든 항목의 **방향은 GlanceShift 우호적**(통제감·자연스러움·재사용 ↑, 흐름끊김 ↓).
> 단, α=.05 기준 유의에 도달한 항목은 **없음**(소표본). 효과크기는 통제감·재사용·흐름끊김이 **중간(≈0.5)**.

## 3. 해석

**(1) "겉보기 평균차 vs 차이값 분산" — 재사용의향이 교과서적 예시.**
재사용의향은 평균이 3.27 → 4.82 로 **격차(+1.55)가 가장 크다.** 그런데도 t=1.85, p≈.094 로
유의하지 않다. 이유는 **차이값의 분산이 크기** 때문(sd=2.77). 개인별 diff 를 보면 +6,+3,+1,+1,**−5**,…
처럼 한 명은 오히려 베이스라인을 크게 선호해, 큰 평균차를 변동성이 깎아먹는다. → 교수님이 지적하신
"평균차가 커 보여도 분산 따지면 차이가 안 날 수 있다"가 그대로 나타난 사례.

**(2) 효과는 있으나 표본이 작아 유의에 못 미침(underpowered).**
통제감·재사용·흐름끊김의 **효과크기는 중간(d_z≈0.5–0.6)** 으로 작지 않다. 방향도 일관되게
GlanceShift 우호적이다. 다만 n=10–11 로는 검정력이 부족해 p<.05 에 닿지 못한다 — "차이가 없다"가
아니라 "이 표본으로는 단정 못 한다"로 읽어야 한다. 통제감·재사용은 n=11 에서 p≈.05–.10 의 **경계
수준**.

**(3) 중복행을 빼면 유의성이 약해진다 — 그래서 n=10 이 더 보수적.**
n=11→n=10 으로 가면 모든 p가 커진다(예: 통제감 .078→.146). 동일 응답 1건이 차이값 분산을 줄여
t를 부풀렸던 것. 중복 포함이 "더 유의해 보이는" 쪽이므로, **제외(n=10)가 더 정직·보수적**이다.

**(4) t-검정 ↔ Wilcoxon 은 대체로 일치.** 방향·크기 순서가 같다. 통제감 n=11 에서만 Wilcoxon(.054)이
t(.078)보다 약간 더 유의하게 나오는 정도. 결론을 뒤집는 불일치는 없다.

**(5) 자연스러움만 약함.** 4항목 중 자연스러움은 효과크기(0.23–0.29)·p값 모두 가장 약하다.
"적응 필요"라는 자유응답과 일치 — 학습곡선이 남아 있는 지점.

> **다중비교:** 항목 4개를 각각 검정했다. 탐색적 파일럿이므로 비보정 raw p 를 보고한다.
> (Holm-Bonferroni 보정 시 어차피 유의 항목 없음.)

## 4. 한계
- **소표본**(n=10–11): 검정력 부족. 유의하지 않음 = 효과 없음이 **아님**.
- **중복행 불확실성**: "응답자 11명" 기억 vs "완전 동일 행 1건" — n=10/n=11 양쪽 제시로 갈음.
- **행동 로그는 참가자 1명(P01)** 뿐 → 추론통계 불가, **기술통계만**
  (`summary_behavioral_descriptive.csv`, 1차 분석 §2 참고). 조건 간 trial 비교는 경향 참고용.
- **가정**: 설문1 의 연속 2행=동일인 페어링, 설문2 의 조건 순서(앞=베이스라인).
